# 实施计划：返回栈修复与剩余闭环

状态：已完成。依据 `specs/2026-08-13-resilience-update-calendar-protection.md` 的已确认总体方案，按风险优先切片交付。

## Task 1：守护拦截后的返回栈修复

**验收标准：**

- 守护命中危险设置页时，关闭危险页后只返回手机桌面，不自动拉起被控端。
- 用户之后手动打开“手机守护”时，直接显示“已绑定，守护生效中”。
- 连续两次进入无障碍关闭页或卸载页，均可拦截且不会形成返回循环。

**验证：** `:kid:testDebugUnitTest`、`:kid:assembleRelease`、OPPO A92s 真机任务栈检查。

## Task 2：远程更新闭环（兼容模式）

**验收标准：**

- 周期检查发现新版本后自动下载并完成清单、包名、版本、大小、SHA-256 和签名证书校验。
- 下载/校验/等待安装/失败/升级成功状态持久化并随心跳回报，失败自动重试且不留下半包。
- 当前设备非 Device Owner 时明确请求系统安装确认；不得宣称或模拟静默安装。

**验证：** core/kid 聚焦单测、错误 APK 矩阵、真机安装流程。

## Task 3：异常事故生命周期

**验收标准：**

- 同一设备同一异常使用稳定去重键，形成 OPEN / ACKNOWLEDGED / RESOLVED 状态和次数。
- 权限恢复后自动关闭对应事故，管理端可确认事故并查看首次、最近和恢复时间。
- 离线、权限关闭、更新失败、版本落后、规则未应用均能形成明确事故。

**验证：** core 聚合器单测、CloudBase 读写测试、双端真机故障注入。

## Task 4：规则可操作性补齐

**验收标准：**

- 周中、周末、假期三套规则继续独立保存；支持选择连续假期范围和补班日期。
- 支持有到期时间的临时加时，过期自动失效且断网不无限延长。
- 管理端显示规则 revision 是否已在被控端应用。

**验证：** core 日期/到期边界单测、admin 构建、双端真机同步。

## Task 5：韧性与防护状态补齐

**验收标准：**

- 通知权限、自启动、电池优化、Usage Access、悬浮窗、无障碍、Device Admin 状态统一上报。
- 开机和覆盖更新后无需打开 UI 即恢复心跳、更新检查和健康基线。
- 管理端不把兼容模式显示成 Fully Managed，并明确系统级防删能力不可用。

**验证：** kid/admin 单测、lint、双端构建、OPPO 重启与权限撤销矩阵。

## Checkpoints

- 每个任务先写失败测试，再做最小实现并运行聚焦测试。
- 每完成 2 个任务运行一次相关模块完整测试与构建。
- 最终运行 core/kid/admin 测试、lint、release/debug 构建和五轴评审。
