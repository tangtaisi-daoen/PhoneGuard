# 真机验收清单（OPPO A92s + 管理端手机）

> 验收前：双端安装最新 APK（见 docs/install.md），管理端已登录，被控端已绑定并完成引导页全部步骤。

## M1 账号与绑定

- [ ] 管理端注册/登录（admin01）成功，重启 app 保持登录
- [ ] 管理端「生成/刷新邀请码」显示 6 位邀请码
- [ ] 被控端输入邀请码绑定成功，显示"已绑定，守护生效中"
- [ ] 云端 bindings 集合 status=BOUND（可选：控制台查看）

## M2 规则

- [ ] 管理端规则页：设置抖音 1 分钟/天 → 保存下发
- [ ] 被控端心跳 90 秒内同步规则（验证：拦截生效即可确认）

## M3 统计与报告

- [ ] 被控端开启"使用情况访问"后正常使用 3 分钟
- [ ] 管理端「使用报告」刷新：被控端显示"在线"、有 app 时长数据
- [ ] 拔掉 A92s 网络 5 分钟 → 管理端「使用报告」显示"离线"

## M4 实时拦截

- [ ] 抖音使用满 1 分钟 → 被踢回桌面 + 提示"本应用今日时长已用完"
- [ ] 再次打开抖音 → 立即被拦截（当日额度用尽）
- [ ] 设置 21:00-7:00 禁玩时段（把系统时间调到 22:00 模拟）→ 打开抖音立即被拦截
- [ ] 微信/浏览器正常使用不受影响（白名单外 app 无规则不拦截）
- [ ] 电话/短信/桌面/设置不被误伤

## M5 防护层

- [ ] 引导页 5 项全部"已开启"（用量/无障碍/电池/自启动/设备管理器）
- [ ] 直接卸载「手机守护」→ 被系统拦截，无法卸载
- [ ] 停用设备管理器 → 90 秒内管理端收到"防卸载被解除"通知
- [ ] 关闭使用情况访问 → 管理端收到"权限被关闭"通知
- [ ] 关闭无障碍 → 管理端收到"权限被关闭"通知
- [ ] 把系统时间回拨 10 分钟 → 管理端收到"时间被修改"通知
- [ ] 安装一个新 app → 管理端收到"新安装应用"通知
- [ ] 管理端「异常通知」列表能看到以上全部事件
- [ ] 被控端杀后台后（测试进程被杀），90 秒内恢复心跳（前台服务 + 自启动 + 电池优化配合）

## M6 夜间保活（可选，耗时）

- [ ] 被控端锁屏放置一夜，次日确认心跳未中断（管理端报告仍有数据）

## 已知限制

- 拦截依赖无障碍服务与使用情况访问，两项被关闭会失效（但会通知管理端）
- 防卸载不防 root/刷机（设备管理器机制局限）
- OPPO/ColorOS 不同版本自启动设置入口可能不同（引导页已做多入口兼容）
