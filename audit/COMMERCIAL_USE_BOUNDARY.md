# PhoneGuard 商业使用边界说明（AGPL-3.0-or-later）

> 状态：阶段三交付物（2026-08-14），随 LICENSE 生效
> 性质：工程合规说明，不构成法律意见；重大商业决策请咨询律师。

## 1. 一句话结论

**个人用户自由使用；任何人对修改版的分发或网络服务提供，都必须按 AGPL-3.0 提供对应源码——"闭源收费"因此不可行，但"收费+开源"始终合法。**

## 2. 个人与家庭使用（无任何限制）

- 下载、安装、使用、修改、自建后端、自行分发，全部自由；
- 无需署名、无需付费、无需登记（保留版权与许可证声明即可）。

## 3. 公司 / 商业主体的边界

| 场景 | AGPL-3.0 下的结论 |
|---|---|
| 原样使用官方发布的 APK 或官方后端服务 | ✅ 允许（无额外义务） |
| 预装/销售/分发**修改版** APK | ⚠️ 必须以 AGPL-3.0 向接收者提供修改版完整源码 |
| 通过网络向用户提供**修改版**服务（SaaS / 云托管） | ⚠️ AGPL §13：必须向交互用户提供修改版对应源码 |
| 分发**原样** APK 并收费（含应用商店上架） | ⚠️ 允许收费，但用户有权取得源码并可自由再分发（收费模式无法封闭） |
| 闭源收费（不分发源码、不提供源码获取途径） | ❌ 违反 AGPL，授权自动终止 |
| 内部自用（不对外提供网络服务、不分发） | ✅ 允许（不触发开源义务） |

## 4. "个人免费" vs "禁止商业闭源收费"的法律差异（用户须知）

1. **AGPL 不禁止商业**：OSI 定义要求开源许可证不得限制商业使用，AGPL 完全合规（opensource.org/osd）。
2. **AGPL 防的是"闭源"而非"收费"**：GPL 系许可证允许收费（"You may charge any price or no price"），但源码必须随分发/网络服务提供；接收者拿到源码后可免费再分发，商业公司无法独占。
3. **AGPL 比 GPL 多堵一条路**：把修改版跑成网络服务（SaaS）也触发源码提供义务（§13），防止"只卖服务不开源"。
4. **若想给公司开"闭源商用"通道**：需要双许可（AGPL + 商业授权），由著作权人单独出具商业许可，并引入 CLA——当前未启用，未来可加。

## 5. 本项目特有的提醒（托管与更新渠道）

- 公开仓库中的环境 ID / 更新 URL 若保留真实值，任何公司可直接复用你的 CloudBase 免费体验版资源（配额有限）。发布前按决策占位符化。
- 被控端远程更新清单由 `release-keys/update-manifest-private.pem` 签名：公司若想伪造更新推送，需持有该私钥（私钥仅本地保管，公开仓库不含）——签名机制本身即商业防护边界之一。
- 商标：AGPL 不含商标授权；"PhoneGuard" 名称与图标的商标保护如需启用，另行声明。
